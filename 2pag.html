Guia Visual: Imagem de Fundo (Background)

Para definir uma imagem como plano de fundo de um site, utilizamos as propriedades de background no CSS aplicadas diretamente na tag body.

body {
  background-image: url('sua-imagem.jpg'); 
    /* Caminho do arquivo */
  background-size: cover;              
    /* Cobre a tela inteira */
  background-repeat: no-repeat;        
    /* Não deixa repetir */
}

O exemplo prático desta propriedade está aplicado aqui mesmo, no fundo desta página!

Guia Visual: Figura no Canto Superior

No HTML, inserimos a imagem com a tag <img>. Depois, no CSS, usamos position: absolute; para descolá-la do fluxo e fixá-la no topo esquerdo do navegador.

<!-- Estrutura no HTML -->
<img src="css.png" class="figura-superior">


    /* Estilização no CSS */
.figura-superior {
  position: absolute;
  top: 15px;  
    /* Distância do topo */
  left: 15px; 
    /* Distância da esquerda */
}

Como por exemplo: Veja a imagem "css.png" declarada e posicionada no topo esquerdo!

Guia Visual: Figura Alinhada à Direita

Inserimos a tag no HTML e aplicamos position: fixed; no CSS. Isso trava o elemento na lateral direita do navegador, fazendo com que ele acompanhe a tela mesmo durante a rolagem.

<!-- Estrutura no HTML -->
<img src="html&css.webp" class="figura-direita">

/* Estilização no CSS */
.figura-direita {
  position: fixed;
  right: 15px; 
    /* Grudada na lateral direita */
  top: 50%;   
    /* Centralizada na altura da tela */
}

Como por exemplo: Veja a imagem "html&css.webp" fixada e acompanhando a lateral direita!

Guia Visual: Estrutura de Formulários

Formulários em HTML usam a tag <form> para agrupar campos de entrada de dados como textos, e-mails e senhas.

<form>
  <!-- Campos de dados exigidos -->
  <input type="text">  <!-- Endereço -->
  <input type="email"> <!-- E-mail -->
  <input type="password"> <!-- Senha -->
</form>

No CSS, usamos regras como .input-group { display: flex; } para alinhar as etiquetas (labels) e as caixas de digitação verticalmente, garantindo um visual limpo.
