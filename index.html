Introdução ao Desenvolvimento Web

O HTML (HyperText Markup Language) é a linguagem de marcação utilizada para construir a estrutura e o esqueleto de uma página web, definindo onde ficam os textos, títulos, imagens e links.

O CSS (Cascading Style Sheets) é a folha de estilo usada para dar vida, cores, posicionamento e design a essa estrutura criada pelo HTML. Juntos, eles formam a base visual de qualquer site na internet.

Guia Visual: Comandos Básicos de HTML

Veja como estruturar os elements essenciais de uma página utilizando as tags fundamentais do HTML:

1. Estrutura Base do HTML

Todo arquivo HTML precisa de uma fundação padrão. Ela avisa o navegador que o documento é uma página web e configura os dados principais.

<!DOCTYPE html> <!-- 
    Define o documento como HTML5 -->
<html>  
        <!-- Tag principal que envolve todo o site -->
  <head>       
   <!-- Configurações internas (título, links CSS) -->
    <title>
        
    Título da Aba</title>
  </head>
  <body>        <!-- Onde fica todo o conteúdo visível do site -->
    Conteúdo visível aqui...
  </body>
</html>

2. Tags de Título (<h1> a <h6>)

Definem a importância e a hierarquia dos textos. O <h1> é o título principal (maior), diminuindo até o <h6>.

Título H4 (Importante)

Título H6 (Menor hierarquia)

Código: <h4>Texto</h4>

3. Tag de Link (<a>)

A tag <a> cria hiperligações para conectar páginas. O atributo href indica o endereço de destino do clique.

Clique aqui para acessar

Código: <a href="url">...</a>

4. Listas (<ul> e <li>)

A tag <ul> cria uma lista com marcadores de pontos. Cada item da lista deve ser envolvido pela tag interna <li>.

Ilustração: Imagem Centralizada

Para centralizar uma imagem na tela usando CSS básico, você deve transformar a tag de imagem em um bloco (display: block;) e definir as margens laterais como automáticas (margin: 0 auto;).

Código para Centralizar:

HTML: <img src="html5.png" class="img-centralizada">
CSS: .img-centralizada { display: block; margin: 0 auto; }
